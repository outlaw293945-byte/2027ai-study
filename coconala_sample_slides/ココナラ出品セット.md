## 6. アップロードする画像（制作サンプル3種）

雰囲気の違う3ジャンルのサンプルが用意できています。
ココナラでは複数画像を登録できるので、各サンプルの「表紙」を中心に混ぜて載せると、
「いろんな業種・トーンに対応できる」ことが伝わり、受注率が上がります。

### サンプル1：こども英会話（明るいコーラル系）
フォルダ：`出品用_ポートフォリオ画像`
- 1_メイン画像_表紙.png ← メイン画像（1枚目）候補
- 2_特徴.png / 3_レッスンの流れ.png / 4_料金プラン.png
- 5_先生紹介.png / 6_よくある質問.png / 7_お問い合わせ.png

### サンプル2：個別指導塾（信頼のネイビー系）
フォルダ：`出品用_ポートフォリオ画像_塾`
- 1_メイン画像_表紙.png / 2_選ばれる理由.png / 3_合格実績.png
- 4_入塾までの流れ.png / 5_料金プラン.png / 6_よくある質問.png / 7_お問い合わせ.png

### サンプル3：ピアノ教室（上品なプラム＋ゴールド系）
フォルダ：`出品用_ポートフォリオ画像_ピアノ`
- 1_メイン画像_表紙.png / 2_3つの魅力.png / 3_コース案内.png
- 4_体験レッスンの流れ.png / 5_月謝案内.png / 6_よくある質問.png / 7_お問い合わせ.png

### 載せ方のおすすめ
- メイン画像（1枚目）：一番「おっ」と目を引く表紙を1つ（ピアノ or 英会話がおすすめ）
- 2枚目以降：3ジャンルの表紙＋料金表など、テイストが違うものを混ぜる
- ※各画像に「※サンプル制作例です（実在の教室ではありません）」と一言添えると親切

## 7. 出品手順（ココナラ画面での操作）

1. ココナラにログイン → 右上「出品する」
2. カテゴリ：「ビジネス代行・相談・士業」→「資料作成・パワポ作成」あたりを選択
3. タイトル・キャッチコピー・説明文・FAQ を上記からコピペ
4. 料金プラン（ベーシック/スタンダード/プレミアム）を設定
5. 画像をアップ（セクション6参照。3サンプルの表紙＋料金表などを混ぜる／1枚目＝一番目を引く表紙）
6. 公開！
