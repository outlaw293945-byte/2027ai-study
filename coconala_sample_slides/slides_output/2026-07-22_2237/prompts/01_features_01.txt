[Design Guidelines]
# Design Specifications（こども英会話教室・入会説明会）

## トーン
あたたかく、親しみやすく、明るい。保護者（30〜40代の母親層が中心）が「ここに通わせたい」と安心できる雰囲気。手書き風のやわらかさと清潔感を両立。堅苦しいビジネス感は避ける。

## 写真・イラストスタイル
- 明るい自然光、パステル基調のやわらかいトーン
- 子どもが笑顔で学ぶシーン、先生とのあたたかい交流
- 実写風よりも、やさしいフラットイラスト／水彩タッチを優先
- 多国籍・多様な子どもたち、清潔で明るい教室

## 配色パレット

### ブランドカラー（Primary）
- Primary: #F4845F - あたたかいコーラルオレンジ。見出し、アイコン、ボタン、強調に使用
- Primary Light: #FDECE5 - コーラルの薄い背景。ハイライト、注目ボックスの背景
- Primary Dark: #D9603B - 高コントラストが必要な場面、白テキストの背景

### アクセントカラー
- Accent Teal: #3AAFA9 - さわやかなティール。図表の第2系列、差別化アクセント
- Accent Yellow: #FFC857 - サニーイエロー。ハイライト、楽しさの演出

### セマンティックカラー
- Success: #4CAF7D - 完了、推奨（やわらかいグリーン）
- Warning: #FFB020 - 注意、要確認
- Info: #4A90D9 - 参考情報、補足

### グレースケール
- Gray-900: #33322E - 見出しテキスト（真っ黒より少しやわらかい墨色）
- Gray-700: #5C5A54 - 本文テキスト
- Gray-400: #A9A69E - キャプション
- Gray-200: #E8E5DE - 罫線
- Gray-100: #F7F4EE - カード背景（あたたかいオフホワイト）
- ベース: #FFFFFF - スライド背景

### 配色ルール
- 1スライドあたり最大3色（グレースケール除く）
- 60-30-10ルール: 60%ニュートラル、30%Primary Lightまたは背景色、10%アクセント
- あたたかみを優先し、彩度は中程度に抑える

## フォント
- 見出し: 太めで丸みのあるゴシック（子ども向けのやわらかさ）
- 本文: 丸ゴシック系、読みやすさ重視、やや大きめ

## 技術仕様
- アスペクト比: 16:9
- 解像度: 2752x1536px (2K)
- フッター: なし
- 余白: 全辺に6%程度（ゆったり）

## レイアウトパターン

### Pattern A: スプリット(左右対比)
左50%テキスト + 右50%ビジュアル。比較・対比に。

### Pattern B: プロセス・フロー
左→右または上→下の流れ。角丸ボックス + やさしい矢印。手順・スケジュールに。

### Pattern C: グリッド・コンテナ
等分割グリッド。アイコン付き角丸カード。3〜5個のポイントに。

### Pattern D: センター・フォーカス
画面中央に大きな要素。重要な数字・結論・キャッチコピーに。

### Pattern G: 全画面ビジュアル + オーバーレイテキスト
全画面イラスト背景 + 半透明ボックス + 白抜き文字。表紙・導入に。

### Pattern H: アイコンマトリクス
アイコングリッド。よくある質問・チェックリストに。

### Pattern J: データビジュアライゼーション
料金比較表・グラフ。あたたかい配色で。
