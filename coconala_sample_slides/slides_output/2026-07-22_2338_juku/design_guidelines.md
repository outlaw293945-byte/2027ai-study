# Design Specifications（個別指導塾・保護者向け説明会）

## トーン
信頼感・誠実さ・落ち着き。中学生・高校生の保護者が「ここなら安心して任せられる」と感じるプロフェッショナルな雰囲気。堅すぎず、あたたかみも少し残す。実績と面倒見の良さが伝わるデザイン。

## 写真・イラストスタイル
- 清潔感のある自習室・個別ブース、集中して学ぶ中高生
- 講師が生徒に寄り添って教えるシーン（1対1〜1対2）
- 落ち着いた自然光、すっきりした構図
- フラットイラストと、ややリアルめの学習シーンを併用

## 配色パレット

### ブランドカラー（Primary）
- Primary: #1F4E8C - 信頼のネイビーブルー。見出し、アイコン、強調に使用
- Primary Light: #E8EEF6 - 青系の薄い背景。ハイライト、注目ボックスの背景
- Primary Dark: #143560 - 高コントラストが必要な場面、白テキストの背景、中扉

### アクセントカラー
- Accent Green: #2E9E6B - 成長・合格を表すグリーン。図表の第2系列、成果の強調
- Accent Orange: #E8873B - 行動喚起（CTA）、ポイント強調に少量

### セマンティックカラー
- Success: #2E9E6B - 合格、達成（Accent Greenと共用）
- Warning: #E8873B - 注意、締切
- Info: #3A7BD5 - 補足情報

### グレースケール
- Gray-900: #1C2530 - 見出しテキスト
- Gray-700: #45505E - 本文テキスト
- Gray-400: #97A1AD - キャプション
- Gray-200: #E3E7EC - 罫線
- Gray-100: #F4F6F9 - カード背景
- ベース: #FFFFFF - スライド背景

### 配色ルール
- 1スライドあたり最大3色（グレースケール除く）
- 60-30-10ルール: 60%ニュートラル、30%Primary Lightまたは背景色、10%アクセント
- ネイビーを基調に、成果・合格はグリーン、CTAはオレンジで締める

## フォント
- 見出し: 太めのゴシック（信頼感・力強さ）
- 本文: 読みやすいゴシック、適度に大きめ

## 技術仕様
- アスペクト比: 16:9
- 解像度: 2752x1536px (2K)
- フッター: なし
- 余白: 全辺に6%程度

## レイアウトパターン

### Pattern A: スプリット(左右対比)
左50%テキスト + 右50%ビジュアル。Before/After・対比に。

### Pattern B: プロセス・フロー
左→右または上→下の流れ。学習ステップ・入塾までの流れに。

### Pattern C: グリッド・コンテナ
等分割グリッド。アイコン付きカード。3〜5個の特徴に。

### Pattern D: センター・フォーカス
画面中央に大きな数字・成果。合格実績・満足度に。

### Pattern G: 全画面ビジュアル + オーバーレイテキスト
全画面写真背景 + 半透明ボックス + 白抜き文字。表紙・CTAに。

### Pattern H: アイコンマトリクス
アイコングリッド。よくある質問・サポート一覧に。

### Pattern J: データビジュアライゼーション
料金表・成績アップのグラフ・合格実績。ネイビー＋グリーンで。
